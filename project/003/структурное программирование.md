# Теорема о структурном программировании


>Любая программа, заданная в виде блок-схемы, может быть представлена с помощью трех управляющих структур:
>
>последовательность - обозначается: f THEN g.
>
>ветвление - обозначается: IF p DO f,
>
>физ бит
канал фрейм
сет пак
транс сегм
сеанс дан
предс
прикл
>цикл - обозначается: WHILE p DO f,
>
>где f, g - блок-схемы с одним входом и одним выходом
>
>p - условие
>
>THEN, IF, ELSE, WHILE, DO - ключевые слова
>
>Пояснение. Формула f THEN g означает следующее: сначала выполняется программа f, затем выполняется программа g

## Принципы структурного программирования

1. Следует отказаться от использования опреатора безусловного перехода goto
2. Программа строится из трех базовых конструкций: 
* последовательность 
* ветвление 
* цикл
3. В программе управляющий конструкции могут быть вложены друг в друга
4. Повторяющиеся элементы можно оформить в виде подпрограмм процедур и функций 
5. Каждую логически законченную группу инструкций следует оформить как блок
6. Все инструкции должны иметь один вход и выход
7. Разработка программы ведется пошагово, методом **сверху вниз** (*top-down-method*);

```pascal
program Number_1;
var hour, minute, n:longint;
ch:char;

begin
writeln('работа первой программы');

repeat
writeln('введите значение секунд');
readln(n);
hour:= n div 3600;
minute:= n div 60 - hour*60;
writeln('получено часов=', hour, 'минут=', minute);
writeln('проверить время еще раз? n - для выхода из программы');
readln(ch);
until ch='n';

end.
```
